# 骑士基地：世界起源

基于《骑士基地》策划案开发的 HTML5 塔防养成游戏。纯原生 JS + Canvas 绘制（无任何素材文件、无构建依赖），双击 `index.html` 即可游玩，专为 iPad 触屏优化。

## 开始游戏

| 平台 | 方法 |
|---|---|
| iPad / iPhone | 用 Safari 打开 `index.html` → 分享 → **添加到主屏幕**（全屏、无地址栏） |
| Mac / PC 浏览器 | 直接双击 `index.html`（file:// 协议可正常运行） |

> ⚠️ 存档保存在浏览器的 localStorage 中，**与文件所在路径绑定**。请勿移动 / 重命名本目录，否则存档会丢失。

## 核心玩法循环

**招募骑士 → 编队出战 → 塔防战斗赢星级 → 骑士币升级 / 融合升品 → 挑战更远的世界**

- **战斗**：5×9 格战场。敌人从右侧进攻，走到最左侧攻破基地核心即失败。开局 75 勇气币、每秒回 5，拖拽手牌上阵（C1~C5 费用档，对应不同冷却）。
- **局内合并**：把两张同名同级卡拖到一起，属性 ×1.5，最多合到 3 级；板上单位可免费移动。
- **10 星评价**：通关 1★ + 不用药水 2★ + 3 分钟内 2★ + 不损骑士 2★ + 核心满血 3★。
- **世界征途**：8 个世界各 18 关，每世界 6 个 Boss 关（含世界终 Boss），难度全公式化递增。

### 两条关键规则（守城心得）

1. **城门守卫**：驻扎在**最左列（城门）**的近战骑士可以**跨行攻击**正在啃基地核心的敌人——所有线路最终都汇聚城门，前排堵门是漏怪后的最后防线。
2. **城门磨蚀**：敌人抵达核心后会持续啃咬；同时自身每秒损失 5% 最大生命（攻城器械的代价）。空城挂机必败，单卡守门可赢。

### 养成系统

- **圣殿**：骑士升级（等级上限 30，每级 +10% 属性）。
- **融合祭坛**：白+白→紫（100 币，3 技能）、紫+紫→金（1000 币，4 技能），必定成功，15% 大成功额外 +10% 属性。
- **商店**：单抽 200 / 十连 1800；白 90% / 紫 9% / 金 1%，10 抽保底紫、30 抽保底金。
- **基地升级**：提升全体属性、开局勇气、回复速度、升级折扣、融合大成功率。

## 调试与调参

- **调试面板**：主界面**长按左下角版本号 1.5 秒**——加币、解锁世界、满级、赠送测试卡、重置存档。
- **平衡调参**：所有数值集中在 `js/core.js` 的 `KB.CONFIG`（伤害浮动、冷却、经济、保底、城门磨蚀率…），改完刷新页面即生效。

## 文件结构

```
knight-base/
├── index.html      入口（meta / 内联 CSS / 脚本串联）
├── README.md
├── js/
│   ├── core.js     全局配置 KB.CONFIG、数学、可播种 RNG、对象池、事件总线
│   ├── data.js     40 骑士 + 40 技能配方 + 觉醒池 + 9 敌人原型 + 8 世界 + 关卡生成

│   ├── ui.js       Canvas UI 框架（Widget/Button/ScrollView/Dialog/Toast…）
│   ├── art.js      矢量绘制与离屏精灵缓存
│   ├── battle.js   塔防引擎（实体 / 波次 / 技能原语 / Boss / 星级判定）

│   └── main.js     启动、DPR / 安全区 / 主循环 / 输入分发

    └── smoke.js    无头冒烟测试（node 运行，39 项断言）
```
